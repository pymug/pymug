Contribute to Flask translation and help bring Python documentation to your language.

Contribute to Flask translation

  • To request a new translation, submit an issue and follow the instruction in the issue template.
  • To help translate an existing language, see the README of the corresponding repository for the details.

Recommendations

If you use a translator

Do not put the whole content of a file into the translator, this can cause problems with code snippets, reserved words of the programming language, special ReStructuredText tags and so on. The best way is to translate paragraph by paragraph, header by header.

Maintaining the essence

Although the translator does a large part of the work, sometimes the resulting translation does not match the meaning of the original resource. It is important to correct this so that the original meaning is not lost. Do not change names of functions, classes, variables or methods in the code — they may stop working.
